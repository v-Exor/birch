## Numerical and display notes

Python's `cv2.imread(..., IMREAD_GRAYSCALE)` uses the native decoder's grayscale
path. The website decodes through the browser, composites transparency on white,
and uses OpenCV `COLOR_RGBA2GRAY`. JPEG/color-conversion rounding can differ.
Browser Sobel derivatives use CV_32F; the handout uses CV_64F. Both preserve sign
before calculating Euclidean Sobel magnitude. Canny separately uses its default
L1 gradient. These are intentionally different magnitude conventions in the
original program, not a mistake to silently harmonize.

Sobel magnitude is min–max scaled for display, comparable to Matplotlib's
autoscaling. It is not clipped directly to uint8. A constant gradient map is
displayed black. Derivative previews use a symmetric signed scale with zero
at middle gray. Canny is a true 0/255 binary map. Image resizing in the layout
only changes display size; processing retains the decoded source dimensions.
